# Safety and Authorization Rules

These companion projects are for defensive education, local analysis, owned systems, and environments where you have explicit permission.

## Allowed use

- Analyze local or synthetic logs.
- Verify file integrity.
- Normalize indicators already provided to you.
- Build incident timelines from local evidence.
- Review saved email headers.
- Redact sensitive values before sharing diagnostics.
- Inventory evidence files.
- Review account exports against an approved policy.

## Out of scope

Do not adapt these projects for unauthorized access, credential collection, malware delivery, destructive actions, persistence, evasion, stealth, or scanning systems you do not own or have permission to test.

## Data handling

Use synthetic data for demonstrations. Do not commit secrets, buyer information, real credentials, private incident data, or paid manuscript files to this public repository.

## Reporting problems

If a contribution would weaken these boundaries, open an issue describing the defensive learning objective instead of submitting risky code.

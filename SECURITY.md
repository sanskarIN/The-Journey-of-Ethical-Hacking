# Security and Responsible Use

This repository is for defensive and authorized learning.

Do not use examples against systems, accounts, networks, applications, services, or devices that you do not own or have explicit permission to assess.

## Reporting repository security issues

Please report security issues privately to:

**sanskarin@outlook.in**

Do not include real passwords, access tokens, private keys, personal data, or sensitive production evidence in a public issue.

## Safety scope

Repository maintainers may reject content that meaningfully facilitates unauthorized access, credential theft, malware, stealth/evasion, destructive actions, bypass of security controls, or targeting of real third parties.

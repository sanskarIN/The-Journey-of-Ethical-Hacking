## Before contacting support

- Check the README and relevant documentation first.
- Include the file/path and a clear description of the problem.
- Do not send passwords, access tokens, private keys, personal data, or sensitive production evidence.
- For a repository security vulnerability, follow `SECURITY.md` and report it privately.

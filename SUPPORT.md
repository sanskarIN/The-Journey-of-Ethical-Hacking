# Support

For questions about the companion repository, documentation corrections, publication-resource suggestions, or safe-learning improvements, contact:

**sanskarin@outlook.in**

## Before contacting support

- Check the README and relevant documentation first.
- Include the file/path and a clear description of the problem.
- Do not send passwords, access tokens, private keys, personal data, or sensitive production evidence.
- For a repository security vulnerability, follow `SECURITY.md` and report it privately.

This repository does not provide assistance for unauthorized access, bypassing security controls, credential theft, malware, destructive actions, or targeting real third-party systems.

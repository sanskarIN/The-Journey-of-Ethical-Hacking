# Authorization Checklist

Use this checklist before any security assessment, validation exercise, lab, or evidence review.

- [ ] Written permission exists.
- [ ] Systems, services, applications, accounts, and data in scope are identified.
- [ ] Allowed methods are documented.
- [ ] Prohibited methods are documented.
- [ ] Time window and responsible contacts are documented.
- [ ] Stop conditions and escalation paths are documented.
- [ ] Evidence-handling and privacy rules are documented.
- [ ] Recovery and rollback expectations are documented.
- [ ] Third-party dependencies are accounted for.
- [ ] Results will be shared only with authorized recipients.

If authorization is unclear, stop and obtain clarification before proceeding.

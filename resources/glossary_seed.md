# Defensive Security Glossary Seed

- **Asset:** A system, service, application, dataset, device, process, or capability that has value to an organization.
- **Authorization:** Explicit permission defining what security work is allowed and under what conditions.
- **Control:** A safeguard intended to reduce risk or achieve a security objective.
- **Evidence:** Information used to support a security observation, validation result, or decision.
- **Exposure:** A condition that may increase the likelihood or impact of a security event.
- **Finding:** A documented control gap or security observation supported by evidence.
- **Least privilege:** Granting only the access necessary for an approved task.
- **Residual risk:** Risk remaining after controls or treatments are applied.
- **Resilience:** The ability to prepare for, withstand, recover from, and adapt after disruption.
- **Synthetic data:** Artificial data created for testing or learning without using sensitive real-world information.
- **Threat model:** A structured representation of assets, trust boundaries, threats, assumptions, and mitigations.
- **Validation:** Evidence-based confirmation that a control or security outcome behaves as intended.

This file is intentionally concise and can grow through safe documentation contributions.

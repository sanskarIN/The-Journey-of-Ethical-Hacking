# Defensive Learning Resources

This directory contains reusable, authorization-first templates and checklists for safe study and defensive security work.

## Categories

- Authorization and scope
- Lab safety
- Findings and remediation
- Evidence logging
- Control validation
- Risk tracking
- Incident observation
- Recovery exercises
- Learning-stage navigation
- Mastery tracking
- Defensive glossary seed

Keep examples fictional, local, isolated, supplied, or explicitly authorized. Never place real credentials, secret values, unnecessary personal data, or third-party target information into shared templates.

# Repository Structure

```text
.
├── .github/                 # CI, issue and pull-request templates
├── datasets/                # Synthetic CSV data only
├── docs/                    # Usage and repository documentation
├── resources/               # Defensive checklists and templates
├── tests/                   # Unit tests for offline utilities
├── tools/                   # Local-only defensive analysis helpers
├── README.md
├── LICENSE
├── NOTICE
├── BOOK_CONTENT_LICENSE.md
├── SECURITY.md
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
├── SUPPORT.md
├── ROADMAP.md
├── CHANGELOG.md
└── what_changed.md
```

The public repository intentionally excludes the paid master manuscript, commercial publication PDF/EPUB, cover, certificates, and store assets.
